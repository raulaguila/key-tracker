# Protótipos históricos

[Documentação atual](../README.md) · [Design atual](../../DESIGN.md)

Estes materiais registram decisões de interface e marca. São demonstrações
independentes com dados de exemplo; não substituem o aplicativo desktop.

| Estudo | Conteúdo | Situação |
| --- | --- | --- |
| [Interface compacta](compact/README.md) | Navegação, densidade e teclado visual | Base histórica; o produto evoluiu para drawers, novos temas e Dobra |
| [Klavra × Dobra](identity/README.md) | Logos, ícones, paletas e telas comparativas | Dobra foi a identidade adotada |
| [ZIP dos estudos](klavra-dobra-estudos.zip) | Snapshot para comparação offline | Arquivo histórico, preservado como produzido |

Cada README informa como abrir seu estudo. Os arquivos HTML/CSS e os pacotes de
comparação permanecem como snapshots; nomes/cores anteriores não representam a
identidade atual. Recursos atuais estão no [guia de marca](../BRAND.md).
