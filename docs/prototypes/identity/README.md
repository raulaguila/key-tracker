# Klavra × Dobra — estudos de identidade

> **Estudo histórico.** Dobra foi a identidade adotada. O comparador e seu ZIP
> preservam as duas propostas; recursos atuais estão no [guia da marca](../../BRAND.md).

Abra `index.html` no navegador. Não é necessário instalar dependências ou acessar
a internet. Os dois estudos estão no mesmo comparador e usam os mesmos dados de
exemplo. Não há captura de teclado, persistência do produto ou execução de ações.

- **Klavra:** uma tecla em camadas com monograma K; framboesa e grafite; letras
  mais contidas. Direção precisa, discreta e modular.
- **Dobra:** um D construído como uma superfície dobrada; cobre e neutros;
  letras com maior peso. Direção próxima, tátil e versátil.

## Como comparar

Use Identidade para comparar as duas propostas ou ampliar uma. Aparência filtra
Claro/Escuro/Ambos. Na prévia é possível pausar/retomar, alternar camadas, buscar
ações e alternar Tabela/Teclado. Os demais controles informam que são demonstração.
Clique em uma cor para copiar seu código (o navegador pode limitar clipboard
quando aberto diretamente como arquivo). Imprimir estudo usa a impressão nativa.

Cada estudo inclui logo para fundo claro, logo para fundo escuro, símbolo
monocromático e ícone SVG. As telas claro/escuro são capturas reais do HTML.
A tipografia usa a família do sistema para funcionar offline. O lettering dos
logos ainda usa texto SVG: o desenho final deverá fixar a tipografia e converter
letras em contornos após a escolha da direção.

Os códigos HEX da paleta representam cores de referência da marca. A interface
usa variantes OKLCH específicas para manter contraste nos dois temas; as cores
semânticas de ativo/pausado permanecem independentes da cor da marca.

## Entregáveis

- `index.html`, `identity.css`, `identity.js`: comparador independente.
- `assets/`: oito arquivos SVG, quatro para cada proposta.
- `previews/`: vistas dos dois estudos e quatro telas separadas em JPEG.
- `validation.json`: resultados de verificação do comparador.

Os nomes são hipóteses criativas, não marcas ou domínios liberados para uso.
Este estudo não modifica o nome, ícone ou aparência do aplicativo instalado.
